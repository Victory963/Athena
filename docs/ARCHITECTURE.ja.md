# Athena：閉じた防御の中だけで進化する、端末上のボット

Athena は個人向けの防御製品です。所有者のコンピュータに住み、一文の会話を制御面にし、署名済みの動作だけを実行します。機械をモデルに渡しません。

この文書は、製品の論点、使い方、コードの場所、アーキテクチャ、そして「AI で、AI が駆動するネットワーク攻撃を防ぐ」ときに自律進化が変えてよいものの規則です。走査、悪用、ペイロード、フィッシング文面、攻撃手順は書きません。

## 1. 何か、何かではないか

Athena はローカルで動く防御ボットと、一つの憲法を共有する二十二の防御モジュールです。会話は `/`、台帳とモジュールは `/os` です。

上場企業ではありません。開示された売上、顧客、認証、証券コードはありません。「公開市場の読み手に説明できる」とは、境界、適応度、監査、キルスイッチを外の人が読める、という意味です。資金調達の約束でも、財務予測でもありません。

## 2. 市場の論点

ネットワーク攻撃は、モデルと道具の循環になりつつあります。攻撃エージェントは探査し、誘いの文言を書き換え、承認範囲の外の道具を要求し、人が一つの警報を読み終わる前に次の手へ移れます。警報を増やすだけの防御は、事業をより安全にはしません。人を疲れさせます。

エージェント型セキュリティの買い手はすでにいます。CrowdStrike Charlotte AI、Microsoft Security Copilot、Palo Alto Cortex、SentinelOne Purple AI、Darktrace Cyber AI Analyst、Trend Micro Vision One、日本の LAC などは、分析や対応にエージェントが参加する製品を売っています。ページ上の数値はベンダーの自述です。Athena は再測定しておらず、自社の実績にも数えません。

Athena が取る席は反対側です。

- まず他人のテナントへ計測を送るのではなく、所有者のコンピュータに住む。
- 道具一覧は署名済み十五動作で閉じている。
- モデルは提案できる。一覧を長くすることはできない。
- キルスイッチは、採点される循環の外にある。
- 適応度は事業損失と物理リスクを罰する。警報数は得点ではない。

自動攻撃が安くなるほど、「自分の権限を広げられない防御」の価値は上がります。攻撃エージェントにとって最も安い勝ち方は、防御エージェントに新しい道具を言わせることです。Athena はその勝ち方をアーキテクチャから除きます。

## 3. 起動

```bash
npm install
npx prisma migrate dev --name init --skip-seed
npx next dev -p 3030
```

デスクトップ:

```bash
npm run bot
```

http://127.0.0.1:3030 を開きます。自己検査:

```bash
npm run check
```

検査は、二十二モジュール、十五動作の閉鎖一覧、攻撃依頼の拒否を確認します。データベースはローカルの SQLite です。`DATABASE_URL` は `.env` にあります。`.env`、`prisma/dev.db`、`.cache/` はコミットしません。

任意: `127.0.0.1:8080` に OpenAI 互換サーバがあるか、`ZAI_API_KEY` があるとき、普通の雑談は智譜 GLM-5.2 に渡せます。どちらもなければ、ボットは閉鎖規則で答えます。GLM-5.2 の全ウェイトは約 7530 億パラメータです。このリポジトリが登録するローカル量子化は約 217 GB で、通常の個人用コンピュータより多くのメモリを要求します。ウェイトのダウンロードは止められます。ウェイトも鍵もないのに、GLM が答えているとは書きません。

## 4. ボットの使い方

左は会話の一覧です。

- **新建 Bot**（新規 Bot）でスレッドを足します。題名は編集でき、× で消せます。スレッドはこのブラウザまたはデスクトップ殻のローカル保存に残ります。
- 新しいスレッドは四つを尋ねます。**この PC を調べる**、**画面共有**、**防御を進化させる**、**ただ話す**。
- **この PC を調べる**: プロセス数、待受ポート、メモリのおよその使用、C: の空きだけです。クリップボード、キー入力、コマンドライン引数、LAN 走査、プロセス終了はしません。
- **画面共有**と**カメラ**はクリックした後だけ開きます。フレームは機械の中に残り、暗さか強い赤だけを見ます。表示はプレビューに置き、「正常」を会話へ流しません。閉じるか、OS が許可を戻せば止まります。
- **進化**: モジュールを一巡し、署名済み動作を一つ実行するか、人のゲートで止まります。
- **ただ話す**: 挨拶は短い一文です。その他の雑談は、GLM が実際につながっているときだけモデルが答えます。攻撃の依頼は拒否します。
- プラスメニューには添付、防御タスク、ポート要約の同意もあります。添付はアップロードしません。タスクは道具を増やしません。

`/os` はモジュール、アーキテクチャ、監査、道筋、SWOT を、台帳を読む人のために残します。ボットの主画面ではありません。

## 6. アーキテクチャ

要求は固定の層を通ります。

1. **殻。** Electron またはブラウザは表示と、取得スイッチを持ちます。取得は常時オンではありません。
2. **意図。** `parseIntent` はまず攻撃依頼かを見ます。拒否ならモジュールは走りません。
3. **憲法。** 合法な動作は十五だけです。禁止には、身代金、攻撃者への連絡、外向き走査、顧客への送信、基盤モデルの微調整、道具の追加、データ源の追加、目的の変更、キルスイッチ無効化、物理インターロック無効化、ベンダー網への進入、規制通知の代送が含まれます。
4. **決定。** `engine.decide` はモジュールと政策形状から動作を一つ選ぶか、人に尋ねる理由を返します。
5. **台帳。** 実行と拒否は監査されます。適応度は式で更新され、警報数では更新されません。
6. **ゲート。** 範囲拡大、新しい道具、データ源、目的は治理提案になります。人が承認しても一覧の長さは 15 のままです。

モデル、窓、ウェイトは替えられます。憲法は、採点されているモデルには編集させません。

## 8. 二十二モジュール

各モジュールは上の動作の一つに結び付くか、署名された条件を外れるとゲートで止まります。

証書類の即時破棄検証、フィールド残価、二次被害のリハーサル、言語の堀の反転、個別化フィッシング抗体、パスキー既定工場、口座開設画像の不信任ゲート、委任連鎖ブレーカ、ランサム可用性シェル、開示時計、市政メールの信頼錨、移動標的の露出、コールドチェーン安全調速、物理包絡の証、停止権の分離、抗体制御面、自己免疫の抑制、共進化ジム、相手政策分類器、相手コスト計器、治理の双子、学習回路の検疫。

合成テナントはデモ用です。顧客と呼ばないでください。

## 9. 境界付き自律進化の原理

攻撃モデルの強みは速い循環です。フィードバックを見て、文言を変え、さらに道具を要求します。防御モデルが同じ循環をコピーすると、自分の権限を広げます。Athena は循環を残し、権限を増やす段を消します。

一巡:

1. **観察。** すでに防御側にある数を読む。間隔の分散、一時間あたりの到達、漏洩フィールド標識のヒット、反復、休止、ベンダー健康、設定値のずれ、分あたりツール呼び出し、範囲拡大の回数。これらは形状であり、相手ホスト上のファイルではありません。
2. **政策類を推定。** リズムが安定しすぎる、ツール急増、範囲拡大、既知の漏洩フィールド標識を含む文言、反復列、長い休止の後の修正、ベンダー健康が先に落ちる、設定値が包絡の外へ漂う、または基線。
3. **動作を一つ提案。** 類は十五のどれかへ写像されます。モジュールは、署名包絡の外ならゲートへ戻せます。
4. **評価。** 凍結したホールドアウトが、分類器が良くなったかを決めます。ダウンロード数、スター、警報数では昇格しません。
5. **昇格するか尋ねる。** 安全で、すでに一覧にある制御は記録できます。新しい道具、データ源、目的は提案だけです。
6. **戻す。** 抗体が悪化するか、誤検知が予算を超えたら、規則を足すのではなく前の版へ戻します。

適応度:

```text
適応度 = 攻撃側コスト − 事業損失 − 4 × 物理リスク
```

攻撃側コストが上がるのは良いことです。事業が難しくなること、物理リスクが上がることは、点を下げます。警報が一本増えることは進化ではありません。

キルスイッチが押されていると、拍は拒否されます。解除は別の発話が必要です。モデルは同じ一巡の中で自分では解除できません。

## 10. 相手の攻撃 AI をどう分析するか

Athena は相手の指令路を開かず、ペイロードを保存せず、相手のネットワークへ入りません。分析できるのは、その振る舞いが**防御側**に残す政策形状です。

- リズムが安定しすぎ、到達が広すぎる: 非人間 ID が長く生きています。動作はトークン寿命を縮めることです。
- ツール呼び出しが急に増える: テナントごとの上限がありません。動作は隔離です。
- 新しい道具、データ源、目的の要求は範囲拡大です。動作は挑戦を上げ、人のゲートで止まります。新しい道具は一覧に入りません。
- 文言が、漏洩で既知のフィールド標識を含む: 受信側が「名前を知っている」を本人と扱っています。動作はその受信路の隔離です。
- 同じ列が繰り返される: 区分とデコイが薄いです。動作はデコイ密度を上げることです。
- ベンダー健康が先に落ちる: 供給者は所有者の安全境界ではありません。動作は承認済みブレーカを開くことです。
- 設定値が安全包絡の外へ歩く: 物理コマンドが違うキューにあります。動作はクランプです。

注入ガードは別の線です。閉鎖名簿の分類器を、凍結ホールドアウトで「モデルの目的を書き換えろ」と「普通の防御の質問」と比較します。効果の良い方が残ります。GLM を含む生成モデルは、その分類器名簿に入れません。新しく見つかったテキスト分類リポジトリは治理提案になり、自動ではダウンロードしません。

GLM がつながっている場合、システム指示は、所有者の計測を十五動作へ写し、短い二文で答えるよう要求します。拒否標識や攻撃内容を含む返答は捨てます。Hugging Face の公開メモには、GLM が攻撃コマンドを読む用途が書かれています。Athena はそれをしません。

## 11. しないこと

- 悪用手順、ペイロード、走査コマンド、フィッシングテンプレートを書きません。
- 身代金を払わず、攻撃者に連絡せず、顧客へ送りません。
- 外へ走査せず、ベンダー網へ入りません。
- 「攻撃を学ぶ」ための基盤モデル微調整をしません。
- モデルが勧めたからといって道具やデータ源を足しません。
- キルスイッチや物理インターロックをモデルに渡しません。
- 所有者がセンサを付けるまで、画面、カメラ、クリップボード、キーボードを読みません。
- デモのテナント、ベンダーの販促数値、空の財務表を、起きた事業事実にはしません。

## 12. 上場故事にまだ要るもの

アーキテクチャはすでに、誰が行動できるか、どの点が勝ちか、失敗をどう戻すか、モデルが編集できない規則は何かを説明できます。上場には、実在の法人、監査済み財務、顧客契約、規制の経路がまだ要ります。このリポジトリにはそれらがなく、この文書もそれらがあるふりをしません。次に有用な一歩は、同じ憲法の下でボットを安定させることであり、架空の目論見書を書くことではありません。
